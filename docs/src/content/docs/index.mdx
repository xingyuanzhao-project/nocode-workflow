import { Card, CardGrid } from '@astrojs/starlight/components';

## What it does

<CardGrid>
  <Card title="Upload your data" icon="document">
    Import a CSV or JSONL file with one text record per row — news articles, survey responses, case reports.
  </Card>
  <Card title="Build a processing flow" icon="setting">
    Drag nodes onto a visual canvas. Chain processing steps: summarise, classify, extract labels. Each step gets its own prompt and output schema.
  </Card>
  <Card title="Attach a codebook" icon="list-format">
    Define classification categories and label options. The codebook is injected into the LLM prompt automatically — no prompt engineering required.
  </Card>
  <Card title="Run and export" icon="rocket">
    Process rows concurrently against any OpenAI-compatible model. Resume interrupted runs from the last checkpoint. Export results as CSV.
  </Card>
</CardGrid>

## Designed for

- **Political science** — coding legislative texts, media reports, human rights documentation.
- **Computational social science** — structured content analysis on large corpora.
- **Any domain** where tabular text data needs systematic LLM processing with reproducible codebooks.
